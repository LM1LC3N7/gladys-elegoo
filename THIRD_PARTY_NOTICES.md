# Third-party notices

This integration ports to JavaScript knowledge of the Elegoo SDCP protocol
held by the following project: the status tables of the FDM printers
(Centauri Carbon), their times counted in seconds, the field names of the
nozzle, bed, enclosure and fans, the printer families by model name, and the
print control commands. No code is copied, and nothing of it is installed at
runtime; its notice is reproduced as a credit.

## SDCP V3.0.0

<https://github.com/cbd-tech/SDCP-Smart-Device-Control-Protocol-V3.0.0>

The public protocol description published by Shenzhen CBD Technology for
Elegoo's mainboards: discovery, WebSocket, topics, heartbeat, commands, status
and error tables. Used as a specification; no text or code of it is shipped.
